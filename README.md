# 이찬미 | RTL Design & Verification

취업용 포트폴리오 웹사이트: https://ichanmi1009.github.io/

## 파일
- `index.html`: 메인 화면 + 프로젝트 상세 페이지 템플릿
- `style.css`: 디자인과 반응형 레이아웃
- `projects.js`: 12개 프로젝트 내용
- `main.js`: 프로젝트 필터와 상세 페이지 동작

## 수정 방법
- 자기소개와 경력은 `index.html`
- 프로젝트 내용은 `projects.js`
- 색상과 디자인은 `style.css`
- 동작 및 상세 페이지 연결은 `main.js`에서 수정한 후 Commit changes를 클릭합니다.

모든 변경사항은 동일한 웹사이트 URL로 다시 배포됩니다.
